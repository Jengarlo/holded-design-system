## 5. Componentes

### 5.1 Banner (top bar)

Barra superior de **48px** de alto con fondo oscuro. Contiene un mensaje promocional a la izquierda y contacto de ventas a la derecha.

Elementos clave: icono + texto promocional ("Empieza ahora y ahorra 50% durante 3 meses"), teléfono de ventas.

### 5.2 Navbar

Barra de navegación de **60px** de alto. Contiene:

- **Logo Holded** (120px de ancho, alineado a la izquierda)
- **Menú de navegación**: Funcionalidades, Empresas, Autónomos, Asesorías, Recursos, Precios
- **Botones CTA**: "Acceder" (secundario) + "Prueba gratis" (primario) — 215px de ancho combinado, 36px de alto

### 5.3 Hero — Variante centrada (Home)

Layout de **1440×1043px**, fondo con gradiente radial y efectos de radiance. Contenido centrado con:

- Título (H2, centrado): "Facturación y mucho más"
- Subtítulo (B2, centrado)
- Dos botones: CTA primario + enlace secundario "Aprende más"
- Imagen del producto debajo (1280px de ancho, rounded corners)

### 5.4 Hero — Variante split (Facturación)

Layout de **1440×728px**, dos columnas:

- **Columna izquierda** (620px): badge de categoría + título H2 + subtítulo + botones CTA
- **Columna derecha**: captura de pantalla del producto con UI real

### 5.5 Botones

| Variante | Estilo | Alto | Uso |
|---|---|---|---|
| `Button 2` (Primario) | Fondo `#1963EF`, texto blanco, border-radius | 48px | CTA principal: "Prueba gratis" |
| `Button 3` (Secundario / Link) | Sin fondo, texto oscuro, underline o flecha | 48px | Acción alternativa: "Aprende más" |
| `Button 4` | Variante terciaria / outline | Variable | Acciones secundarias |
| `Button 5` | Variante compacta | Variable | Uso en cards y features |
| `Button / with icon` | Botón con icono incorporado | Variable | Acciones contextuales en UI |
| `Buttons` (Navbar) | Compact, 36px alto | 36px | "Acceder" + "Prueba gratis" |

### 5.6 Feature Cards

Tarjetas para mostrar funcionalidades del producto. Estructura:

- Icono o imagen del producto
- Título (H6 o H7)
- Descripción (B3 o B4)
- Enlace de acción opcional

### 5.7 List of Features

Sección de ancho completo con múltiples columnas mostrando funcionalidades. Incluye iconos, títulos cortos y descripciones.

### 5.8 Testimonial / Quote

Bloque de cita destacada con:

- Foto de avatar del cliente
- Texto de cita (estilo destacado)
- Nombre y cargo del cliente

Texto de ejemplo: _"Toda la empresa habla el mismo idioma gracias a Holded"_

### 5.9 Stats Section

Bloque con métricas destacadas (números grandes):

- Valores numéricos con `H2`/`H3` como "40%", "160", "80%"
- Labels descriptivos en `B4`

### 5.10 CTA Final

Sección de cierre con fondo oscuro/gradiente:

- Título: "Prueba Holded gratis durante 14 días"
- Botón CTA primario
- Ancho completo

### 5.11 All-in-one Features

Sección que muestra múltiples módulos del producto (Facturación, Contabilidad, CRM, etc.) con:

- Tabs o badges de categoría
- Imagen del producto
- Título descriptivo
- Lista de funcionalidades
