# Holded Web Design System

Sistema de diseño web extraído del archivo de Figma **Brand Elements Web**, basado en las páginas **Home** y **Facturación**.

## Archivos

| Archivo | Descripción |
|---|---|
| [`holded-design-system.md`](./holded-design-system.md) | Documentación completa en Markdown — tokens, tipografía, colores, componentes, patrones y CSS custom properties |
| [`holded-design-system.html`](./holded-design-system.html) | Guía visual interactiva — misma información renderizada como página web con previews en vivo |

## Contenido

- **Tipografía** — Inter Display + Inter, escala completa H2–H8 y B2–B4
- **Colores** — Primarios, grises (50–900), semánticos, sub-marca Aprende
- **Sombras** — 2 niveles de elevación (base y s2)
- **Botones** — Primario, secundario, navbar, outline
- **Layout** — Contenedor 1280px en viewport 1440px, padding 112px
- **Componentes** — Banner, Navbar, Hero (centrado y split), Feature Cards, Testimonials, Stats, CTA
- **Patrones de página** — Estructura de bloques de Home y Facturación
- **CSS Custom Properties** — Variables listas para copiar al proyecto
